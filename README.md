# Trigonometry

Step-by-step practice apps for CP2U7 (right triangle trigonometry), one for each skill section of the test.

Open `index.html` for the list of apps. Each app is a single self-contained HTML page:

1. trig-ratios-from-a-point.html
2. missing-sides.html
3. missing-angles.html
4. solving-right-triangles.html
5. angle-of-elevation.html

Progress is saved in each student's browser (localStorage). Nothing is sent anywhere.
